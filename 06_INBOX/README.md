# INBOX

新发现先记录在这里。一条信息对应一个 Markdown 文件，文件名可用日期、项目及短标题。每条填写以下字段，可复用 [调研模板](../templates/research-template.md)。

- 来源（可共享的链接、证据路径、Git 提交或用户确认）
- 日期（YYYY-MM-DD，必要时补来源发生时间）
- 所属项目（项目名，跨项目内容注明“跨项目”）
- 信息类型（观察、事实记录、推断、经验候选或待确认决策）
- 验证状态（待验证、已核实、有冲突或已证伪）
- 内容和下一步（结论或问题、已知证据、缺口与复核方法）

证据不足时保留原验证状态。整理完成后补充整理日期、验证结论及目标文件链接。整理方式见 [Dreaming](../05_WIKI/dreaming-protocol.md)。
