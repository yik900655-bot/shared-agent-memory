# Roblox Font Generator

低成本工具站练习项目。首版目标是让用户输入文字、查看 Unicode 样式并单独复制，附按 Roblox 目标字段验证过的兼容性说明。

当前已建档，下一步是 45～60 分钟的三竞品同输入体验和目标字段实测。通过后约一天完成单页 MVP。上线后观察约 30 天，再按真实数据决定继续或暂停。
