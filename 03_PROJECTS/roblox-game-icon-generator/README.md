# Roblox Game Icon Generator

产品目标是提供 Roblox 游戏图标生成工具。

当前阶段是最小 MVP 市场验证。英文首版让用户输入游戏名称和描述，生成、预览并下载一张 512×512 PNG。先验证单张真实交付，再用上线后 30 天的搜索与使用数据决定是否继续投入。多风格、批量生成和复杂图片处理暂缓。

按已确认的交付顺序，先在本地做出可用网站，再考虑正式部署。当前阶段与下一步见 [当前项目](../../02_CURRENT_STATE/current-project.md)。
