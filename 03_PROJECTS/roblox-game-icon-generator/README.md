# Roblox Game Icon Generator

产品目标是提供 Roblox 游戏图标生成工具。

第一版计划支持用户上传游戏截图、填写描述、选择风格，生成 2～3 个图标方案，预览并下载 PNG。

按已确认的交付顺序，先在本地做出可用网站，再考虑正式部署。当前阶段与下一步见 [当前项目](../../02_CURRENT_STATE/current-project.md)。

- [底座调研](research.md)
- [技术决策](technical-decisions.md)
- [开发状态和验收](development-status.md)

产品目标和第一版范围来自用户于 2026-11-11 确认的项目资料。
